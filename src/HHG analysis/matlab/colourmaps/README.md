The bundled `devon.txt` RGB table is Fabio Crameri's Scientific colour maps
Devon palette, distributed by [cmcrameri](https://github.com/callumrollo/cmcrameri).
Downloaded 2026-11-04 from the repository's `main/cmcrameri/cmaps/devon.txt`.
The upstream MIT license is included in LICENSE.txt.

Scientific colour maps: https://www.fabiocrameri.ch/colourmaps/
Permanent source citation: https://doi.org/10.5281/zenodo.1243862

This preserves the *named* palette in the supplied TC script without requiring
the missing `crameri` function. The original lab helper's version is unknown.
